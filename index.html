    독립 정반응률 = + 개수 ÷ 전체 시도 수 × 100. P(도움 받고 맞힘)는 맞힌 반응이지만 혼자 한 것이 아니므로 따로 표시하고 독립 정반응률에는 넣지 않아요. '예시' 표시가 있는 회기는 화면을 보여주기 위해 넣어 둔 예시 기록입니다.

    독립 정반응률

    다음 날 확인 (탐침)

    숙달은 이 기록으로 판단해요

    전날 3회기 연습 후, 다음 날 첫 회기 시작 때 컵·숟가락·포크를 촉진 없이 1번씩 물어보고 결과를 적어요.

    일반화 단계

    숙달 뒤에 진행해요. 단계마다 촉진 없이 3개 모두 맞히면 통과로 표시하고 다음 단계로 넘어가요.

    하준이 (가상 학생)

    • 초1 특수학급, 자폐범주성장애
    • 한 단어 발화 일부, 2어절 지시 부분 이해
    • 착석 약 5분, 시선 자주 이탈
    • 모르면 교사 얼굴을 보며 기다리거나 오른쪽 카드를 집음
    • 기차를 매우 좋아함

    할 수 있는 것: 실물–사진 짝짓기, 카드 집어 건네기
    아직 못 하는 것(목표): 사물 이름 듣고 사진 고르기

    목표 (수용언어)

    교사가 "○○ 줘"라고 하면 컵·숟가락·포크 사진 카드 3장 중 맞는 카드를 3초 안에 골라 건넨다.

    사진 카드로 시작하는 이유: 실물–사진 짝짓기가 가능해서, 자극을 일정하게 맞추기 쉬운 사진으로 먼저 가르치고 숙달 후 실물로 넓혀요.

    1. 지금: 급식 도구 "컵 줘"
    2. 다음: 과일 "사과 줘"
    3. 그다음: 동작 지시 "사과 줘 / 만져 / 가리켜"

    1회 시도

    1. 주의집중 확보: "하준아." 시선이 올 때까지
    2. 변별자극: "컵 줘." 한 번만, 같은 말투
    3. 촉진: 0초는 말과 동시에 가리키기, 3초는 기다린 뒤 가리키기
    4. 반응: 3초 관찰
    5. 후속결과: + → "컵! 혼자 찾았네!" + 토큰 / P → "그래, 컵."
    6. 시도 간 간격 3~5초: 카드 회수 → 기록 → 다음 배치

    오류수정 (− 일 때)

    1. 칭찬 없이 카드 회수
    2. "컵 줘." + 즉시 가리키기 → "그래, 컵."
    3. 전환 시도: "손뼉 쳐." → "좋아!"
    4. 위치 바꿔 촉진 없이 "컵 줘." → 맞히면 토큰

    회기 운영 규칙

    • 한 회기 10시도, 사물을 섞어 제시 (같은 사물 2번 넘게 연속 금지)
    • 정답 위치는 좌·중·우 고르게, 같은 위치 연속 금지
    • 토큰 5개 → 기차 영상 1분
    • 하루 3회기(1교시·3교시·점심 후), 회기당 5분·10시도
    • 회기 정반응률이 80%를 넘으면 시간지연을 늘려요 (0초 → 3초)
    • 숙달: 다음 날 첫 회기 시작 때 3개를 촉진 없이 1번씩 확인해 모두 맞히는 날이 이틀 연속 (교재 기준으로 최종 확인)
    • 숙달 후 일반화 4단계: 자료 → 사람 → 장소 → 자연적 상황(급식 시간)
